# Help log sheet (facilitator)

For #182 („Hilfe“ button). Print one sheet per session. The app logs the moment of each press (`help_requested`, real time in `utc`); this sheet adds what kind of help was given, so the two can be matched in the analysis.

**When the trainee presses „Hilfe“** (a soft bell rings, the button shows „Hilfe kommt …“ on the stream):

1. Go to the trainee. First ask: **„Was haben Sie schon versucht?“**
2. Help at level 1 first; go one level up only if that was not enough.
   - **1 Zeigen / point:** show where to look (screen field, card, container), no explanation.
   - **2 Erklären / explain:** explain the rule or the step in one or two sentences.
   - **3 Vormachen / model:** do the step once while the trainee watches, then let the trainee do it.
3. Do not press the red button or answer a question for the trainee.
4. Write one line below. Use the clock on the wall/phone (same time zone as the app log; the log time is UTC).
