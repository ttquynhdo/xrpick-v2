# #13 File export EN–DE cho người bản ngữ duyệt

- **Nhánh:** `main` (đợt cuối, người dùng 2026-11-06: làm mọi việc trừ build)
- **Ngày:** 2026-11-06
- **Decision:** docs/decisions/002-localization-mechanism.md
- **Sửa:**
  - Công cụ mới `docs/i18n/review_tool.py` (Python, chỉ thư viện chuẩn, chạy bằng `python -I`):
    - `export`: tạo `docs/i18n/review/review-<ngày>.csv` (UTF-8 có BOM, CRLF, 8 cột theo skill `localize-strings` mục 4), xếp theo thứ tự bài học, dòng `proposed` lên trước trong mỗi bài, cùng file hướng dẫn tiếng Đức `review-<ngày>-ANLEITUNG.md` (Sie).
    - `import <file> --reviewer "<Tên>"` (có `--dry-run`): đọc `,` hoặc `;`, UTF-8 hoặc Windows-1252.
      - `ja` → `confirmed`.
      - Có `Korrekturvorschlag` → thay chữ DE trong `strings-todo.csv` và ghi `confirmed`, „korrigiert durch Reviewer“.
      - Từ chối cả file nếu có `�`.
      - Dòng có placeholder `{…}` hoặc tag `<…>` khác EN → báo lỗi, giữ nguyên trạng thái.
      - Chỉ ghi lại đúng những dòng đã đổi; các dòng khác giữ nguyên từng byte, kể cả cách đặt ngoặc kép.
  - Bỏ qua các dòng mà `LocalizationBinder` cũng bỏ qua (`= <keys>.*`, `(…)`, `label.*`).
  - File export đầu tiên: `docs/i18n/review/review-2026-11-06.csv`, 211 dòng, cả 211 đều `proposed`.

## Kết quả

Mọi case import chạy trên **bản sao** `strings-todo.csv` / `review-status.csv` trong scratchpad, file thật không đổi.

| Case | Cách test | Kết quả | Bằng chứng |
|---|---|---|---|
| E1 File review mở trong Excel, umlaut hiển thị đúng | code + Bạn | code ✅: file bắt đầu bằng BOM `EF BB BF`, CRLF, cột đúng 8 tên. Phần mở trong Excel: ⏳ Bạn | `od -c` 3 byte đầu |
| E2 Import file mẫu đã điền → `confirmed` | code | ✅ dòng `ja` → `confirmed`, reviewer + ngày; dòng có đề xuất → chữ DE đổi + `confirmed` „korrigiert durch Reviewer“ | console import |
| E3 File do Excel tiếng Đức lưu (`;`, Windows-1252, có ä/ü) import được | code | ✅ „import (cp1252, separator ';'): 1 confirmed, 1 corrected“, umlaut đúng trong `review-status.csv` | console import |
| E4 File có `�` bị từ chối, có báo lỗi | code | ✅ exit 1, „file contains the replacement character … rejected“, không ghi gì | console import |
| E5 Placeholder khác EN → báo lỗi, trạng thái giữ nguyên | code | ✅ `entry.resume.question` bỏ `{participant_id}` → ERROR, exit 1; thêm: `mixed.card.step2_body` mất `<nobr>` → ERROR | console import (`--dry-run`) |
| E6 (code) Import chỉ đổi đúng các dòng được duyệt | code | trước: ❌ ghi lại cả file làm 4 dòng khác đổi cách đặt ngoặc kép; sau: ✅ diff chỉ còn các dòng được duyệt, BOM và CRLF giữ nguyên | `git diff --no-index` |
| E7 Export bỏ đúng các dòng giả | code | ✅ 214 key → 211 dòng (bỏ `menu.items`, `wms.dialog.labels`, `label.material`; `concept.tour.cartons.body` „= 3 Kartons“ vẫn có) | console export |

Trước khi sửa: chưa có công cụ, nên mọi case đều ❌ (không có file để mở hay import).
