# #151 Mặt bàn khớp băng con lăn: hai mép cân nhau

- Nhánh `feat/151-desk-edges` (tách từ `feat/155-text-rule`, 1b00079), ngày 2026-11-18.
- Cách làm: `Environment/Desk` (prefab SDK `MRDesk/Desk`) ở Basic, Mixed, Complex, Concept: `DeskSurface` scale x 1 → 1.166, x 0 → −0.1465 (mặt bàn x −0,75…0,75 → −1,021…0,728, collider theo cùng); `DeskShadow` scale x 1.14 → 1.329, x 0 → −0.1465. Chỉ là override trên prefab instance, không sửa script, không dời vật nào khác.
- Vì sao 5 cm chứ không trùng ray ngoài: ở ConceptScene hai chân trái của `RearBench` đứng ở x −1,02…−0,99, ngay bên trái ray làn trái (−0,971); mặt bàn phải chạy tới đó. Trước khi sửa hai chân này lơ lửng ngoài mép bàn.
- Số đo trước: ray ngoài trái −0,971, phải 0,678; mép bàn −0,750 / 0,750 → bên trái băng thò ra 22,1 cm (lề −0,221), bên phải bàn thừa 7,2 cm; các con lăn làn trái (x −0,951…−0,557) nằm vắt qua mép bàn x −0,75.
